## What teachers, students and parents need first

1. **Teacher daily workspace:** today's assigned lessons, absence/replacement request, unmarked attendance, homework/marks due and one clear Save/confirmation path. Keyboard/mobile actions and error messages should be usable without training on database concepts.
2. **Parent daily workspace:** only linked children, real attendance/homework/fees/transport, next action and confirmation/reference. Missing data should say “not recorded,” not display a demo substitute.
3. **Student workspace:** grade-aware junior/middle/senior content, task completion and helpful feedback. College/university views must come from actual course/semester enrollment, not a cosmetic persona selection.
4. **Administrator exception queue:** missing identity/mappings, expiring documents, unmatched payments, failed messages, substitute conflicts and incomplete imports, all with named owners and audit references.
5. **Adoption pilot:** run the full admit → enroll → attendance → homework → fees → transport/library → exam/report → next-year journey with representative teachers, parents, students and finance staff. Record time, errors, accessibility and corrections; a test-suite pass alone does not establish adoption.

### AI implementation requirements

- **First:** exception summaries from authorised records, teacher-draft notices, grounded lesson-plan drafts and reviewed question suggestions. Show sources, allow editing and require the responsible user to publish.
- **Next:** topic-specific tutoring over licensed class/edition material, with real page/source references, “not found” behaviour, age-appropriate responses and teacher escalation. Evaluate correctness with held-out questions before release.
- **Later:** timetable optimisation and demand/stock planning with explainable constraints, not a black-box allocation; reconcile recommendations against real capacity and budgets.
- **Do not automate:** admission refusal, expulsion, discipline, safeguarding, fee waivers or biometric identity decisions from unverified model output. Retain authorised review, reason/evidence and appeal history.
- **Operational requirements:** tenant/role-safe retrieval, no student-sensitive data in model logs by default, model/provider settings, budget caps, timeout/fallback, prompt-injection controls, review history and correction feedback.

## Regulatory applicability

The reviewed CBSE circular specifies a 75% minimum for Class X/XII board-exam attendance, with the applicable condonation process; it does not establish a universal 80–90% government-school fine rule. The RTE Act and its 2019 amendment contain elementary-education fee/expulsion protections. These need category/state/institution applicability review, not automatic blanket enforcement:

- [CBSE attendance circular](https://www.cbse.gov.in/cbsenew/documents/Strict_Compliance_attendance_Eligibility_05082025.pdf)
- [RTE Act](https://www.indiacode.nic.in/bitstream/123456789/15938/1/the_right_of_children_to_free_and_compulsory_education_act%2C_2009.pdf)
- [RTE 2019 amendment](https://upload.indiacode.nic.in/showfile?actid=AC_CEN_9_9_00006_200935_1517807327595&filename=rte_-amedment%2C_2019.pdf&type=notification)
