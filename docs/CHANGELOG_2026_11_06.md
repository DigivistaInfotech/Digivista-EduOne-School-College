## Essential, conditional and optional

The required-field matrix is in APPLICATION_GAP_REVIEW.md. Identification, scope, amount/date and transaction lines are essential when relevant. Tax evidence, invoice details and document checks become conditional at their relevant action. Blood group, additional contacts, notes and extra audit context remain optional unless an explicitly approved institution policy requires otherwise. Existing records remain compatible; display-only staff assignments do not grant user access.

## Corrections found during combined verification

- Student seed assignments now use self scope; unsupported old school-scoped student grants remain rejected by authorization. No real account grants were rewritten.
- Learning/library scope helpers consider only grants for the relevant action, so unrelated school-wide finance/HR grants cannot widen student records.
- Student dashboard resources exclude staff-only, draft and other-class content. Empty attendance is Not recorded; daily status and homework come from actual records. Advanced subject totals count distinct attendance rows instead of multiplying them across weekly timetable slots.
- Parent child cards display the central admission number instead of labelling a UUID fragment as a roll number.
- The journey-test startup hook uses the existing repository 180-second disposable-database allowance. The invalid section-scoped invented test role was replaced by a valid scoped teacher fixture; application guards were retained.
- Browser checks on the isolated preview verified vendor category persistence, Class 8 plus shared library filtering, term create/edit, live budget item filtering and purchase draft arithmetic: 2 × ₹100 + 18% GST = ₹236. No purchase order/payment was submitted.

## Follow-up: budget figures staying stale

Budget summaries now explicitly refresh on mount and window focus and poll every 30 seconds while visible. The dashboard headline, embedded summary and detail report share that refresh policy.
